A mod manager for Claude Code skills, for Windows.

**Download:** `Loadout-Setup-<version>.exe` below. The installer is not code-signed yet, so Windows SmartScreen may warn: choose **More info**, then **Run anyway**. Loadout updates itself from these releases after that.

- A checked catalog: Anthropic's skills plus 57 community repos, 1,273 skills, each pinned to the commit that was read.
- One-click installs into `~/.claude/skills`; switch each skill On, Name only or Off (Claude Code 2.1.129 or newer).
- Profiles, your own GitHub repos with a safety review, and updates with a file-by-file diff.

How the catalog was checked: [docs/catalog-audit.md](https://github.com/NeekBot5000/loadout/blob/HEAD/docs/catalog-audit.md)
