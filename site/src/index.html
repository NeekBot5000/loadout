Three states for every skill

Each skill that is on puts its name and description in front of Claude at the start of every chat. With a few dozen installed, Claude Code starts dropping descriptions to fit, and you cannot see which. Loadout shows the cost and lets you turn each one down.

StateWhat Claude sees
OnThe name and the full description, so Claude picks the skill up on its own.
Name onlyJust the name. The skill still works when you ask for it, for a few tokens.
OffNothing. The files stay where they are.

Checked before it is listed

Skills are instructions Claude follows, and some include scripts that run on your computer. The catalog came from downloading {{SCANNED}} popular skill repos and reading every file in every skill for prompt injection, hidden text, reading secrets, sending data out and running code from the internet. A person read every serious finding.

{{REPOS}} community repos made it in, each pinned to the commit that was checked. The ones left out are listed with the reason in the audit report. It is a careful check of one version, not a guarantee.

Getting started

Free and open source, for Windows 10 and 11, with Claude Code 2.1.129 or newer. The installer is not code-signed yet, so Windows SmartScreen may warn: choose More info, then Run anyway. Loadout updates itself after that.

  1. Download for Windows and run the installer.
  2. Open Loadout. Skills you already have show up as yours, and your current setup is saved as a profile.
  3. Press Install on a skill, or Enter on a selected row. Switch states with the buttons or Space.
  4. Start a new Claude Code chat to pick up the change.
